# Evaluation scripts

This directory contains scripts for converting RabbitTClust clustering results
to labels and evaluating the resulting clustering.

## Requirements

The C++ utilities require a C++ compiler. Build them from this directory with:

```bash
make
```

The Python metrics require Python 3, NumPy, and scikit-learn:

```bash
python3 -m pip install numpy scikit-learn
```

## Generate a label file with `calLabel`

`calLabel` converts a RabbitTClust clustering result into the two-row label
format consumed by `getNMI.py` and `get_recall.py`:

1. The first row contains the predicted cluster label for each genome.
2. The second row contains the corresponding ground-truth taxonomic label.

Run it as:

```text
./calLabel GROUND_TRUTH {-l|-i} CLUSTER_FILE LABEL_FILE
```

Arguments:

- `GROUND_TRUTH`: ground-truth file containing
  `<accession, taxid, organismName>` per line, with a header on the first line.
- `-l`: the clustering input was a list of genome files (sketch-by-file).
- `-i`: the clustering input was one sequence file (sketch-by-sequence).
- `CLUSTER_FILE`: clustering result generated by RabbitTClust.
- `LABEL_FILE`: output label file.

Example:

```bash
./calLabel bacteria.groundTruth -l bacteria.mst.clust bacteria.mst.label
```

## Compute NMI with `getNMI.py`

`getNMI.py` computes normalized mutual information (NMI) between the predicted
and ground-truth labels using scikit-learn's
`normalized_mutual_info_score`.

```bash
python3 getNMI.py bacteria.mst.label
```

Example output:

```text
bacteria.mst.label:	0.987654321
```

Run `python3 getNMI.py --help` for command-line help.

## Compute pairwise precision, recall, and F1 with `get_recall.py`

`get_recall.py` constructs the pair confusion matrix for the predicted and
ground-truth clusterings, then reports pairwise precision, recall, and F1.

```bash
python3 get_recall.py bacteria.mst.label
```

Example output:

```text
bacteria.mst.label
Precision: 0.9800
Recall:    0.9700
F1-score:  0.9749
```

Run `python3 get_recall.py --help` for command-line help.

## Complete evaluation example

From `benchmark/evaluation`, generate labels and compute both metrics with:

```bash
make
./calLabel bacteria.groundTruth -l bacteria.mst.clust bacteria.mst.label
python3 getNMI.py bacteria.mst.label
python3 get_recall.py bacteria.mst.label
```

## Compute cluster purity with `calPurity`

`calPurity` computes clustering purity and coverage:

```text
./calPurity {-l|-i} GROUND_TRUTH CLUSTER_FILE PURITY_FILE
```

Example:

```bash
./calPurity -l bacteria.groundTruth bacteria.clust bacteria.purity
```

This generates:

- `bacteria.purity`: detailed purity for each cluster.
- `bacteria.purity.accession.purity`: the first genome in each pure cluster.
- `bacteria.purity.accession.unpurity`: the dominant and impure genomes for
  each impure cluster.

## Generate a representative list with `getRepresentativeList`

`getRepresentativeList` chooses one representative genome from each cluster:

```text
./getRepresentativeList {-l|-i} CLUSTER_FILE REPRESENTATIVE_LIST
```

Example:

```bash
./getRepresentativeList -l bacteria.greedy.clust bacteria_representative.list
```
